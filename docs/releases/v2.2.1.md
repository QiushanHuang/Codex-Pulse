# Codex Pulse 2.2.1

## 2.2.1 补丁

- 修复 Xcode 26.3 编译任务用量对比界面时可能超时的问题。
- CI 使用匹配的 Xcode 与 SDK；窗口测试等待主队列完成，减少固定时序带来的不稳定。

以下功能包含 2.2.0 的更新。

## 更新内容

- **界面与操作：**额度页先显示各窗口的剩余额度；任务页默认显示列表，并可直接打开选中的 Codex 会话。设置按常用操作和可展开选项组织，补充信息可通过信息按钮查看。
- **便签与侧边栏：**提供迷你圆环、紧凑和标准便签；圆环可调整大小并临时展开详情。屏幕边缘侧边栏支持左右停靠、跨屏拖动、尺寸调整和自选内容。
- **额度与用量：**分别显示套餐额度、Credit 余额和重置券；支持每日／每周账号 Token、任务累计 Token 对比，以及按时段查看本机记录的 Credit、额度和任务 Token 变化。手动使用重置券前必须确认，结果不确定时沿用同一次请求编号。
- **提醒：**任务状态可通过 Pulse 卡片或 macOS 通知提示，六类事件可分别选择提示音。权限与问题提醒可选连接 Codex Hooks，连接会备份并合并配置，之后仍需在 Codex 中审阅并信任。额度重置可选通过 Bark 或 SMTP 通知。
- **灯效与可访问性：**保留控件标签、状态和必要的错误提示；覆盖自定义预设或恢复外观前会说明后果。颜色代码可直接应用并检查格式，非交互灯效不会在读屏时列出装饰性按键。

### 数据与使用边界

任务列表和任务 Token 来自本机可见记录，不能代表账号所有任务，也不能推算单个任务的 Credit 费用。Credit 历史从开始采集后积累，早于记录的数据无法补录；缺失或过期数据不会当作零。轮次结束不代表任务目标已经验收。详见[用量记录](https://github.com/QiushanHuang/Codex-Pulse/blob/v2.2.1/docs/usage-history.md)和[提醒设置](https://github.com/QiushanHuang/Codex-Pulse/blob/v2.2.1/docs/task-reminders.md)。

## 下载与安装

下载 **`Codex-Pulse-v2.2.1-macos-arm64.dmg`** 或 ZIP，适用于 Apple Silicon、macOS 14 及以上。应用内置 Python 3.13.15 和 Node.js 22.23.2。更新前先退出旧版，再将应用拖入 Applications；现有本地设置和历史数据保留。Codex 需另行安装并登录，G HUB 仅在使用键盘联动时需要。

公开下载包采用 **ad-hoc 签名，未经 Apple 公证**。请核对 `SHA256SUMS.txt` 并参照[首次打开说明](https://github.com/QiushanHuang/Codex-Pulse/blob/v2.2.1/docs/troubleshooting.md)。从使用其他签名身份的版本切换，或更换 ad-hoc 构建后，macOS 可能要求重新授予输入监控权限。本机源码构建可使用固定开发证书；它不等于 Developer ID 公证。

macOS 14 是部署目标，本次未在全新 macOS 14、Intel Mac 或所有键盘／固件组合上验证。系统通知、手机收件与实体键盘表现取决于各自授权和环境。
从源码构建需要 Xcode 26 或更新版本及匹配的 macOS SDK；这与下载包的最低运行系统不同。

## English

Version 2.2.1 fixes an Xcode 26.3 compiler timeout in the task comparison view and
makes the native window checks wait for the main queue. It includes all 2.2.0 features:

- **Interface:** Current quota and task actions are easier to find. Tasks open in list view; settings use expandable groups and accessible information controls.
- **Desktop surfaces:** Choose a resizable mini ring, Compact or Standard sticky card, or an optional screen-edge sidebar with configurable position, size and content.
- **Quota and usage:** Separate subscription quota, Credit balance and reset vouchers. Compare cumulative task tokens and examine account usage or locally recorded history over a selected time range. Voucher redemption requires confirmation; uncertain results reuse the same request ID.
- **Reminders:** Choose Pulse cards, macOS notifications and per-event sounds. The optional permission/question hook connection backs up and merges the Codex configuration and must be reviewed and trusted in Codex. Optional Bark or SMTP notifications report quota resets.
- **Lighting:** Confirm before replacing customized presets or restoring appearance. Color-code entry has an Apply action and validation; decorative keys are excluded from screen-reader navigation for non-reactive previews.

Task records and task Token history cover what this Mac observed, not all account activity. Per-task Credit cost cannot be inferred from them; Credit history begins when recording starts. A finished turn is not proof that a task goal has been accepted.

Download the Apple Silicon DMG or ZIP for macOS 14+. Both include Python 3.13.15 and Node.js 22.23.2. Quit the previous app before replacing it. The public bundle is **ad-hoc signed and not Apple-notarized**; verify `SHA256SUMS.txt` and follow the [first-launch guidance](https://github.com/QiushanHuang/Codex-Pulse/blob/v2.2.1/docs/troubleshooting.md). Changing signing identity may require Input Monitoring authorization again. macOS 14 is the deployment target, not a clean-install test result; Intel and all keyboard/firmware combinations remain unverified.

Source builds require Xcode 26 or newer with a matching macOS SDK. This is separate from the download's minimum runtime version.
