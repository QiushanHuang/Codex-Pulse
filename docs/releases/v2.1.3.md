# Codex Pulse 2.1.3

## 更新内容

- 新增可保存的「设置 → 通用与外观 → 在 Dock 中显示」开关。关闭后保留菜单栏入口，后台监控继续运行。
- 从 Dock 重新打开时恢复工作台或便签；增加隐藏应用菜单入口，并修复旧图标显示。
- 便签采用 Widget 的额度圆环、消耗速度、重置时间、趋势与最近三条任务组合，保留置顶和返回工作台。
- 主界面与便签的深色背景按 Widget 的实际灰青色亮面校准。
- 修复「查看设置」打开时自动出现蓝色焦点框，保留键盘导航的焦点提示。

## 下载与安装

Apple Silicon，macOS 14+。下载 DMG 后将应用拖入 Applications；也可下载 ZIP。
包内包含 Python 3.13.15 和 Node.js 22.23.2，无需另装运行时。
更新前退出旧版；个人配置与历史数据保留。Codex 需另行安装并登录。

**Ad-hoc 签名，未经 Apple 公证。** 首次打开请参考[安装排障](https://github.com/QiushanHuang/Codex-Pulse/blob/main/docs/troubleshooting.md)。
更新后输入监控可能需要重新授权。未验证 Intel、全新 macOS 14 或所有 G HUB/固件组合。
附件包含 DMG、ZIP、SHA256SUMS.txt 和 release-manifest.json。
