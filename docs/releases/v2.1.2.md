# Codex Pulse 2.1.2

A native macOS companion for Codex quota, local tasks and optional G913 lighting.
Created and maintained by [Qiushan (QiushanHuang)](https://github.com/QiushanHuang).

## Downloads

- **Codex-Pulse-v2.1.2-macos-arm64.dmg** — drag the app into Applications.
- **Codex-Pulse-v2.1.2-macos-arm64.zip** — the same app in a ZIP archive.
- **SHA256SUMS.txt** — checksums for downloads and the runtime manifest.
- **release-manifest.json** — pinned runtime sources, versions and integrity hashes.
- GitHub's tagged source archives contain the source and build instructions.

Apple Silicon / macOS 14+. Python 3.13.15 and Node.js 22.23.2 are bundled; no Homebrew,
Xcode or runtime setup is needed for the download. Codex must be installed and signed
in separately. Optional keyboard lighting needs G HUB and a supported full-size G913.

**Ad-hoc signed; not Apple-notarized.** Read the
[first-launch guidance](../troubleshooting.md) before opening a downloaded copy.
The UI is primarily Chinese. English and Chinese documentation is in one README,
with language badges that jump within the page.

## Included

Quota trends and consumption estimates, searchable local tasks, menu-bar indicators,
a pinnable sticky card, WidgetKit extension, explicit device selection, keyboard quota
and task signals, and a 48-preset lighting studio. New release packaging supports moved
app bundles and both Codex.app and ChatGPT.app installation locations. Original
waveform-and-quota artwork is shared by the app and documentation.

## Validation and limits

See [release-validation.md](release-validation.md) for this release's checks. Existing
G913 device evidence does not validate every firmware/G HUB version or G915. The
release target is macOS 14+, but a clean macOS 14 system and Intel hardware have not
been tested. Input Monitoring can require reauthorization after ad-hoc updates. The
widget's refresh and availability are controlled by macOS. No Apple notarization or
clean-machine Gatekeeper acceptance is claimed.
