# 额度重置手机通知

范围：在 Pulse 设置 → 通用增加自定义入口，切换 Bark 手机推送或 SMTP 邮件。默认关闭。可分别选择 5 小时、每周自然重置，以及服务确认成功的重置券操作。仅设置保存及用户点击测试会操作通知凭据；开发验证不向外发送消息。

## 行为与验收

- 自然重置以同一账号、同一窗口的最新服务数据为准：旧重置时间已过，新的重置时间向后推进超过 60 秒。额度下降、倒计时结束、过期数据及账号切换不单独产生通知。
- 手动重置读取现有确认回执，只处理 `completed` + `reset`/`alreadyRedeemed`，按请求编号去重。不发起或自动消耗重置券。
- 外部入口（例如 Tibo）的手动重置通过同账号服务数据交叉识别：完整、计数一致的券列表中，一张或多张尚未到期的券消失，可用次数同量减少；且 Codex 窗口在原自然重置时间之前恢复。两种证据允许在 10 分钟内先后到达，待匹配证据跨重启保留。提醒使用“检测到外部手动重置”，服务数据不提供具体发起应用。
- 券过期、有效期未知、列表不完整、普通额度回升、账号切换、首次启用、超过匹配时限均不单独触发外部重置提醒。券减少和自然重置同时发生且无法区分原因时，仅按自然重置处理。本机成功回执优先，后到的券变化归属同次本机操作，避免重复通知。
- 首次开启及修改接收设置建立新基线，不补发旧事件。SQLite 同一事务保存基线和待发事件，普通重启保留去重记录。
- 独立发送线程使用 HTTPS Bark POST 或 SMTP SSL/STARTTLS。失败最多尝试三次，延迟 60/120 秒；超过一天不再发送。关闭或修改设置取消旧队列。网络超时或进程在发送后崩溃时，远端可能已接收，重试仍可能重复；不承诺跨远端的恰好一次投递。
- 完整推送地址和邮箱授权码放入 macOS 钥匙串，普通配置仅保存非秘密字段。错误日志不包含异常原文或凭据。
- 验证：自然重置、手动回执、账号切换、过期/无效数据、关闭/重新开启、重启去重、失败重试；模拟两种发送协议；原有 Python 回归检查；Swift 应用构建及签名检查。

## 配置

在设置 → 通用 → 额度重置通知中启用，选择接收方式及事件，填入参数并保存。

**Bark：** 在 iPhone 的 Bark App 中复制完整设备推送地址，例如 `https://api.day.app/<设备密钥>`。支持使用自建 Bark 的 HTTPS 设备地址。地址保存在钥匙串。不要把密钥放入源码或截图。接口按 [Bark 官方教程](https://github.com/Finb/Bark/blob/master/docs/en-us/tutorial.md)使用 JSON POST。

**邮件：** 填入 SMTP 主机、端口、加密方式、登录用户名、发件邮箱及收件邮箱。SSL 通常使用 465，STARTTLS 通常使用 587，具体以邮箱服务商设置为准。使用邮箱授权码或应用专用密码。邮件服务器接受发送不代表手机已收到；需手机开启邮件通知。

点击“保存并发送测试”会向填写的地址实际发送一条测试消息。收到后再启用自动通知即可。

Mac 必须联网且 Pulse 监控运行。睡眠/退出期间不发送，恢复后基于最新额度判断；全新安装、没有之前基线的情形不会补发。当前支持 Bark 手机推送；安卓可先使用邮件。SMTP 收件箱垃圾邮件过滤及手机免打扰可能影响实际提示。
